## Interpretation and limitations

1. **Task performance (Figure 2):** Paper, MATLAB, and Python are nearly
   identical. MATLAB–Python correlation is approximately 1.
2. **Metacognitive bias (Figure 3):** The three sources agree closely.
   Differences are concentrated in meta-noise, consistent with the known
   optimizer/interpolation difference.
3. **Response bias (Figure 4):** MATLAB reproduces the published Figure 7
   values closely. Python agrees on the traditional measures but diverges for
   several Ratio/Diff measures.
4. **Precision (Figure 1):** MATLAB uses both Haddara and Maniscalco and
   follows `ana_precision.m`. The current Python cache contains Haddara only
   and intentionally omits the expensive MLE measures (`meta-d'`, `M-Ratio`,
   `M-Diff`), so those Python points are unavailable.
5. **Split-half (Figure 5):** Paper and MATLAB series are labeled as the
   100-trial analysis. The stored MATLAB split-half result cells yield lower
   correlations than the published Figure 7 values. Python caches contain a
   full-data odd/even split, not the same 100-trial binning protocol, so this
   is not a strict like-for-like comparison.
6. **Test-retest (Figure 6):** Paper and MATLAB use 400-trial bins. Python
   uses the full cached day-level estimates. MATLAB closely reproduces the
   paper values; Python is generally higher but preserves the same ranking.
7. **Figure 7:** Heatmaps annotate the raw values. Colors are normalized
   within each metric row solely to make patterns visible; compare printed
   numbers for quantitative interpretation.
